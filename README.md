# Qwen3 Embeddings of O*NET 25.0 Job Codes

This repository contains embeddings of the descriptions of standardized job codes from [O*Net 25.0 database](https://www.onetcenter.org/dictionary/25.0/excel/). Embeddings from the three differently-sized [Qwen3 embedding models (0.6B, 4B, and 8B)](https://arxiv.org/abs/2505.09388) are available in this repository. These embeddings can be visualized using [TensorFlow Projector](https://projector.tensorflow.org/).

- **Qwen3 0.6B:** https://projector.tensorflow.org/?config=https://raw.githubusercontent.com/jeyabbalas/onet-25-0-qwen3-embeddings/refs/heads/main/config_embedding_0_6B.json
- **Qwen3 4B:** https://projector.tensorflow.org/?config=https://raw.githubusercontent.com/jeyabbalas/onet-25-0-qwen3-embeddings/refs/heads/main/config_embedding_4B.json
- **Qwen3 8B:** https://projector.tensorflow.org/?config=https://raw.githubusercontent.com/jeyabbalas/onet-25-0-qwen3-embeddings/refs/heads/main/config_embedding_8B.json
